USER STORY

==========
Auth
==========

- I can register with an email and password to create a personal account
- I can login to access my own pantry and favorites
- I can logout so my session ends securely
- The system confirms/activates new account on register

==========
Pantry
==========

- I can add an ingredient to pantry so I can track what I have at home
- I can view my pantry list so I know what is available to cook with
- I can delete pantry items so my list can stay accurate
- I cannot see or edit another user's pantry items, my data is private

==========
Recipes
==========

- I can search for recipes by an ingredient I have
- I can view a recipe image and title in the search results
- I can request and AI-generated recipe suggestion based on my pantry\

==========
Favorites
==========

- I can save a recipe to my favorites as a reference for later
- I can rate a saved favorite 1 through 5 so I know which are best
- I can remove a favorite recipe so the list only has what I like
- I cannot see or modify another user's favorite items, data is private

==========
Error Handling
==========

- I can see a clear message explaining what to do when a request fails
- I can see a loading indicator while data is being fetched
